
## 1. Create a Python environment

```powershell
conda create -n documind python=3.12 -y
conda activate documind
python -m pip install -r requirements.txt
```

If you already have the environment, omit `conda create` and run the last two commands. Confirm with `python --version`.

## 2. Configure AWS IAM credentials

1. Sign in to the [AWS Console](https://console.aws.amazon.com/).
2. In **IAM → Users**, use a dedicated user for this demo; create an **Access key** under **Security credentials**.
3. Give the user the minimum permissions needed for `s3:PutObject`, `s3:GetObject` on the project bucket.
4. Save the access key ID and secret key securely. Do not paste them into public chats or recordings.
5. Choose `us-east-1` for the examples below (or use the actual region where your bucket is available).

## 3. Configure Cohere and Groq

1. **Cohere API Key (Embeddings):**
   * Sign up at [cohere.com](https://cohere.com/) and grab your free API key.
   * Model: `embed-english-v3.0` (produces 1,024-dimensional embeddings matching Pinecone).
2. **Groq API Key (Chat LLM):**
   * Sign up at [console.groq.com](https://console.groq.com/) and create a free API key.
   * Model: `openai/gpt-oss-120b` (or `llama-3.3-70b-versatile`).

## 4. Create the S3 bucket and add the required CORS

1. Open [Amazon S3](https://console.aws.amazon.com/s3/).
2. Select **Create bucket**, choose a globally unique bucket name such as `documind-documents-your-unique-suffix`, and use the configured AWS region.
3. Leave **Block all public access** enabled and enable encryption.
4. Open your bucket → **Permissions** → **Cross-origin resource sharing (CORS)** → **Edit**.
5. Paste this JSON and **Save changes**:

```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["PUT"],
    "AllowedOrigins": [
      "http://127.0.0.1:8000",
      "http://localhost:8000"
    ],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3000
  }
]
```

**This step is required for the original browser-to-S3 upload version.** It fixed your earlier browser `Failed to fetch` error. Use the exact origin shown in your browser's address bar. If the frontend later runs at a different origin, add that origin as appropriate.

## 5. Configure Pinecone (automatic index creation)

1. Open [Pinecone Console](https://app.pinecone.io/).
2. Create an API key and copy it.
3. **Do not manually create an index.** The project creates `documind-index` automatically on first indexing (or when running the optional check script).
4. The index configuration is **dense vectors, dimension 1024, cosine metric, serverless AWS `us-east-1`**.
5. Your account must allow index creation and have sufficient quota.

## 6. Configure Supabase PostgreSQL

1. Open [Supabase Dashboard](https://supabase.com/dashboard) and sign in.
2. Select your project (or choose **New Project**, specify a project name, secure database password, and your preferred AWS region).
3. In your project dashboard, navigate to **Project Settings** (gear icon in the sidebar) → **Database**.
4. Scroll down to the **Connection parameters** / **Connection string** section and select **URI** (or use Connection Pooling).
5. Copy the connection string. In `.env`, set `DATABASE_URL` to this URI.
   - **Direct Connection:** `postgresql://postgres:YOUR_PASSWORD@db.YOUR_PROJECT_REF.supabase.co:5432/postgres`
   - **Session / Transaction Pooler:** `postgresql://postgres.YOUR_PROJECT_REF:YOUR_PASSWORD@aws-0-REGION.pooler.supabase.com:6543/postgres`
6. If your database password contains special characters (such as `@`, `#`, `?`, `/`), ensure it is URL-encoded.
7. Supabase enforces SSL by default, which is supported automatically by `psycopg`.

Example structure:

```dotenv
DATABASE_URL=postgresql://postgres.YOUR_PROJECT_REF:YOUR_PASSWORD@aws-0-REGION.pooler.supabase.com:6543/postgres
```

## 7. Configure LangSmith and get the API KEY

https://smith.langchain.com/

```dotenv
LANGSMITH_TRACING=true
LANGSMITH_API_KEY="your_langsmith_api_key"
LANGSMITH_PROJECT=documind
```

## 8. Create the `.env` file

In the project root, copy `.env.example` to `.env`:

```powershell
Copy-Item .env.example .env
```

Edit `.env` to contain:

```dotenv
# AWS
AWS_ACCESS_KEY_ID=YOUR_AWS_ACCESS_KEY_ID
AWS_SECRET_ACCESS_KEY=YOUR_AWS_SECRET_ACCESS_KEY
AWS_SESSION_TOKEN=
AWS_REGION=us-east-1
S3_BUCKET=YOUR_PRIVATE_S3_BUCKET_NAME

# Supabase PostgreSQL
DATABASE_URL=postgresql://postgres.YOUR_PROJECT_REF:YOUR_PASSWORD@aws-0-REGION.pooler.supabase.com:6543/postgres

# Pinecone (index created automatically)
PINECONE_API_KEY=YOUR_PINECONE_API_KEY
PINECONE_INDEX_NAME=documind-index
PINECONE_CLOUD=aws
PINECONE_REGION=us-east-1
PINECONE_READY_TIMEOUT=180

# Cohere & Groq
COHERE_API_KEY=YOUR_COHERE_API_KEY
COHERE_EMBED_MODEL=embed-english-v3.0
GROQ_API_KEY=YOUR_GROQ_API_KEY
GROQ_CHAT_MODEL=openai/gpt-oss-120b
EMBED_DIM=1024

# App
HITL_ENABLED=true
MEMORY_TURNS=6
```

If you use temporary AWS credentials, set `AWS_SESSION_TOKEN`; otherwise leave it blank. **Do not set `PINECONE_INDEX_HOST` for this auto-create version.**

## 9. Initialize the database automatically

Run from the project root:

```powershell
python scripts/init_db.py
```

Expected: a success message confirming the PostgreSQL database and **five tables**: `documents`, `feedback`, `audit_events`, `approvals`, and `chat_messages`. The script is safe to rerun with the supplied schema.

If this fails, confirm that your Supabase project is active, the database connection URL is correct, the password has been set properly, and your local network can reach Supabase.



## 10. Run the application

```powershell
uvicorn app.main:app --reload
```

Open these URLs in the browser:

- **App:** http://127.0.0.1:8000
- **API documentation:** http://127.0.0.1:8000/api/docs
- **Liveness:** http://127.0.0.1:8000/health/live
- **Database readiness:** http://127.0.0.1:8000/health/ready

Keep the VS Code terminal running. Use **Ctrl+C** to stop the server.
